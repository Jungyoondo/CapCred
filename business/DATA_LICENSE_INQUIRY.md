# 시세 데이터 이용 문의 문안 (2026-10-18 초안 - 보내기 전 사용자 확인)

> 왜: 첫 유료 계약 전에 시세 원천을 상용 라이선스로 바꿔야 한다(DINTEL_BUSINESS_PLAN 6장 274행).
> 받아야 할 답 3가지: ① 집계 통계(공시 유형별 평균 주가 반응)를 서비스에 표시해도 되는가, ② 가격·차트를 표시하려면 어떤 계약이 필요하고 얼마인가, ③ 학생 창업·파일럿 단계의 조건이 따로 있는가.
> 보내는 것은 사용자가 직접 한다(제가 보내지 않는다). 개인정보·키를 넣지 않는다.

## A. 한국거래소 정보사업(정보이용 계약) 문의
제목: 공시 기반 위험 정보 서비스의 시세 정보 이용 조건 문의

안녕하세요. 고려대학교에서 상장사 공시 기반 재무위험 조기경보 서비스를 준비하고 있는 학생 창업팀입니다.
여신기관(저축은행·캐피탈 등)에 관심기업 공시 경보와 위험 확률을 제공하려 하며, 현재는 비상업 연구 단계입니다.

다음을 여쭙고자 합니다.
1. 일별 종가로 계산한 **집계 통계**(예: 특정 공시 유형 발표 후 20거래일 평균 수익률)를 유료 서비스 화면에 표시하는 것이 정보이용 계약 대상인지
2. 개별 종목의 일별 시세(종가·거래량)를 화면에 표시하려면 어떤 계약 유형이 필요하고, 초기 단계 기업의 이용료는 어느 정도인지
3. 지연 시세(예: 전일 종가)만 쓰는 경우의 조건, 그리고 파일럿(무상 3개월, 기관 2곳) 단계에 적용되는 별도 조건이 있는지

서비스는 매수·매도 의견을 제공하지 않고, 공시와 재무 위험 통계만 제공합니다. 필요하시면 서비스 구조 설명 자료를 보내드리겠습니다.
감사합니다.
(이름 / 소속 / 연락처 - 보내기 전 기입)

## B. 데이터 벤더(예: 코스콤·FnGuide·에프앤가이드 계열 등) 문의
제목: 일별 시세 데이터 API 상용 이용 견적 문의

안녕하세요. 상장사 공시 기반 위험 정보 서비스를 준비하는 초기 팀입니다.
코스피·코스닥 전 종목의 **일별 수정주가(OHLCV)와 상장폐지 종목 이력**을 API나 일괄 파일로 받아 서비스(기관 대상, B2B)에 쓰려 합니다.
1. 상품 구성과 월 이용료(초기 사용자 수 10명 이하 기준)
2. 서비스 화면에 가격·차트를 표시할 때의 재배포 조건
3. 과거 데이터 기간(2010년 이후 필요)과 상장폐지 종목 포함 여부
견적과 이용 조건을 받아볼 수 있을까요? 감사합니다.

## C. 토스증권 Open API 문의 (집계 통계 이용)
제목: Open API 시세로 계산한 집계 통계의 이용 범위 문의

안녕하세요. Open API를 본인 투자 목적으로 이용하고 있습니다.
이용 정책상 '본인 매매 목적 외 이용과 제3자 배포 금지'를 확인했습니다. 시세 원자료가 아니라 그것으로 계산한 **익명 집계 통계**(예: 공시 유형별 평균 반응률)를 비상업 연구 발표나 서비스 시연에 쓰는 것이 허용되는지 여쭙고 싶습니다.
허용되지 않는다면 원자료와 집계 모두 본인 투자 목적으로만 쓰겠습니다. 감사합니다.

## 답을 받은 뒤
- 견적은 DINTEL_BUSINESS_PLAN 6장 '손익분기'에 넣어 다시 계산한다.
- 토스 답변이 '불가'면 성적표·반응 통계의 시세 원천을 공공 원천(금융위 주식시세정보 - 공공누리 4유형, 이용 조건 확인)이나 상용 원천으로 바꾼다.
