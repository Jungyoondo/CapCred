# 파일럿 제안서 (여신기관용, 1장) — dintel × 신용캐드 (2026-10-18 초안)

> 목적: 사업계획서의 가장 큰 미확인 항목인 **여신기관의 지불 의사**를 확인한다(DINTEL_BUSINESS_PLAN 1장 69행, 7장 11월).
> 상대: 저축은행·캐피탈·상호금융·정책금융·P2P·메자닌 펀드의 여신 심사/리스크 담당. 2곳, 무상 3개월.
> 10-20 추가 상대: 은행 **프랜차이즈론**(가맹본부 협약 가맹점주 대출) 심사팀·지역신용보증재단 - 아래 '브랜드 건강도' 트랙.
> 숫자 표시: [실측] 저장소 재현, [확인] 공개 자료, [추정] 가정. 매수·매도 의견은 내지 않는다.

## 1. 귀사의 문제 (한 줄)
담보 종목·메자닌 발행사의 위험을 사람이 공시를 읽어 판단한다. 공시 제목만으로 거르면 큰 급락의 **9~13%**만 잡힌다 [실측].

## 2. 3개월 동안 드리는 것
| 항목 | 내용 | 형태 |
|---|---|---|
| 관심기업 실시간 공시 경보 | 귀사가 정한 기업(담보·발행사)의 공시를 1분 안에 포착하고, 같은 유형 공시의 과거 반응과 위험 태그를 함께 표시 | 웹 화면 + 알림 |
| 월간 조기경보 목록 | 코스닥·코스피 상장사의 12개월 중대 위험 공시 확률 순위. 상위 10%와 근거(공시 연쇄·재무) 포함 | 월 1회 파일 |
| 소상공인 공정신용 리포트 (선택) | 귀사 차주 표본(익명)에 대해 '점수가 낮은 이유' 설명 리포트 | 표본 10~30건 |
| 브랜드 건강도 (프랜차이즈론 트랙) | 귀사 협약·심사 대상 외식 브랜드의 서울 매장 추이, 최근 12개월 개업·폐업, 성장/쇠퇴 3분위, 가맹점 1년 폐업률(업종 대비) | 월 1회 브랜드 리포트 |

## 3. 지금까지의 근거 (코스닥, 2024~25 표본외) [실측]
- 조기경보 상위 10%의 12개월 중대 위험 공시율은 **19.6%**다. 평균의 3.2배이고, 전체 위험의 32%를 미리 잡았다.
- 상장폐지된 497곳을 넣어 다시 검증해도 결과가 유지됐다(생존편향 보정).
- 재무만 보는 모델의 소형사 오경보는 26.4%였다. 공시 연쇄를 더하면 18.5%로 줄었다(-27%).
- (브랜드 건강도, 서울 인허가 실데이터) 매장이 줄어드는 외식 브랜드의 가맹점은 다음 1년 폐업률이 성장 브랜드의 **2.6~7.1배**였다(카페·음식점, 2014~19와 2021~24, 업력을 맞춰도 유지). 지금 쓰이는 정보공개서는 가맹본부의 자기 보고이고 1년 늦다.

## 4. 검증 방식: 봉인 채점 (귀사가 결과를 직접 확인)
1. 시작일에 경고 목록을 **해시값으로 봉인**해 귀사에 먼저 전달한다(나중에 고칠 수 없음).
2. 3개월 뒤와 12개월 뒤에 실제 위험 공시(관리종목, 감사의견, 회생, 대규모 희석 등 사전 정의 목록)로 채점한다.
3. 비교 대상은 귀사의 기존 방식(가능하면)과 무작위 목록이다. 결과가 나빠도 그대로 공개한다(성적표).

## 5. 귀사가 해 주실 것
- 관심기업 목록(종목코드)만 받는다. 차주 개인정보는 받지 않는다. 소상공인 리포트를 원하면 익명 표본만 받는다.
- 월 1회 15분 피드백: 쓸모 있었던 경보와 쓸모없던 경보.
- 종료 시 '유료라면 얼마까지 낼 의향이 있는가'에 대한 짧은 설문.

## 6. 조건과 한계 (정직하게)
- 무상 3개월이고, 계약 의무는 없다. 귀사 데이터는 파일럿 종료 시 삭제한다.
- 시세 기반 화면(가격·차트)은 상용 시세 라이선스를 받기 전까지 표시하지 않는다. 공시(DART) 기반 기능만 쓴다.
- 확률은 과거 같은 유형의 통계이고, 개별 기업의 미래를 보장하지 않는다. 투자·여신 결정은 귀사가 한다.
- 소상공인 점수는 아직 실제 상환 결과로 검증하지 않았다(합성 데이터 MVP). 파일럿 상환 결과가 첫 검증이 된다.
- 공개 데이터만으로는 개별 소상공인 폐업 예측력이 낮다(서울 89만 곳 검정, AUC 0.56~0.62). 그래서 귀사의 상환·현금흐름 결과가 필요하다.
- 브랜드 건강도는 인허가 대장 기반이라 양도는 폐업으로 잡히지 않고, 외식(카페·음식점)에서만 검증됐다.
