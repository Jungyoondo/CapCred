## 10-21 공정위 정보공개서 브랜드 목록으로 외부 검증 (caed/ftc_brands.py, 결과 전 등록)

## 10-21 같은 자리 다음 점포 - 양도·갈아타기 (caed/brand_churn.py, 결과 전 등록)
- **정의**:
  - 같은 자리 = 인허가 좌표 10m 이내.
  - 다음 점포 = 같은 업종 대장에서 폐업 -30~+180일 사이에 인허가 난 가장 이른 업소.
  - 다음 점포가 같은 브랜드면 '같은 브랜드 재개업'(양도), 다른 브랜드면 '갈아타기'.

  - 갈아타기율 = (t-18개월, t-6개월]에 폐업해 다른 브랜드로 바뀐 가맹점 수 / t 매장 수.
- **D2b**: 업력·면적·순증가율에 갈아타기율을 더하면 검증 AUC +0.01 이상, 두 업종 모두.

  - 가맹점 폐업 중 같은 자리 같은 브랜드 재개업(양도)은 카페 3.2%, 음식점 3.7%뿐이었다.
  - 다른 브랜드로 갈아타기는 13.1% / 17.3%였다.
  - D1 **성립**(쇠퇴/성장: 카페 17.0% vs 2.2%, 음식점 9.7% vs 3.3%). '양도 때문에 과대 추정' 한계는 작다고 실측됐다.
  - D2 **성립**(갈아타기 상위/하위: 카페 12.0% vs 2.7%, 음식점 8.1% vs 4.8%).
  - D2b **기각**(AUC +0.007 / +0.008). 갈아타기율은 순증가율과 겹친다. 설명용 지표로만 쓰고 점수에는 넣지 않는다.

## H-2026-10-Z 독립점 첫해 폐업률 급등은 양도(같은 자리 즉시 재개업)가 폐업으로 잡힌 착시다 (등록 2026-10-25, 결과 전)

## H-2026-10-AC 에이전트 사전 채움: 인허가 증감으로 고친 서울 매장 수가 '작년 신고 그대로'보다 올해 신고에 가깝다 (등록 2026-10-25 22:50 커밋 f2dfea4, 결과 10-25 22:52)

- **정의**: `caed.ftc_frcs prefill` - AB2(v2)와 같은 매칭(외식, 정규화 이름 정확 일치, 서울 행). 브랜드-회계년도 t마다 작년 신고 F(t-1)이 10곳 이상인 것만. 실측 M(t) = 회계년도 말 영업 중 인허가 매장 수.

  - 사전 채움: g = (M(t) - M(t-1)) / max(M(t-1), 5), P1 = F(t-1) x (1 + g)
  - 경보: |P1 - P0| >= max(3, 0.1 x F(t-1))인 브랜드-연
- **가설**: AC1 사전 채움 평균 절대오차(매장 수)가 복사보다 10% 이상 작다(MAE(P1) <= 0.9 x MAE(P0)). AC2 신고가 실제로 바뀌고(F(t) != F(t-1)) 실측도 바뀐 브랜드-연에서 부호 적중률 >= 65%. AC3 경보 중 신고가 경보 방향으로 실제 바뀐 비율(정밀도) >= 70%.
- **판정**: AC1·AC3 성립이면 에이전트 리포트에 '예상값·경보'를 싣는다. AC1 기각·AC3 성립이면 숫자 예상값은 빼고 경보만 싣는다. AC3 기각이면 둘 다 빼고 명세 대조만 남긴다. 기준은 결과를 본 뒤 바꾸지 않는다.

  - **대상**: AB2(v2)와 같은 매칭(외식, 정규화 이름 정확 일치)으로 공정위 2025 회계년도 서울 신고 매장 수(빈 신고 제외)가 10곳 이상인 브랜드.
  - **예상값**: P = F2025 x (1 + g), g = (M(2026-09-30) - M(2025-12-31)) / max(M(2025-12-31), 5). M은 서울 인허가 영업 중 매장 수다. 9개월 실측만 쓴다.
  - **경보**: |P - F2025| >= max(3, 0.1 x F2025).
  - **봉인**: 브랜드는 정규화 이름의 SHA-256으로만 적는다. 파일 해시는 `scoreboard/caed_fdd_ledger.csv`에 남긴다. 실명 대응표는 로컬 전용이다.
- **채점**: 2027-10-31에 공정위 지역별 가맹점 수(15125490)를 받아, 2026 회계년도 신고(빈 신고 제외)가 공개된 봉인 브랜드로 잰다.
  - AF1: 평균 절대오차가 '2025 신고 복사'보다 10% 이상 작다.
  - AF2: 경보 정밀도(신고가 경보 방향으로 바뀐 비율)가 70% 이상이다.
  - 둘 다 성립이면 "실전에서도 맞았다"로 공개한다. 기각이면 그대로 공개하고 예상 규칙을 다시 검토한다.
